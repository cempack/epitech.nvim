# Check before you push

**Epitech: Check the Whole Project** (`Ctrl+Alt+B`, or the beaker in the
Epitech sidebar) runs Banana on every tracked file, checks the Makefiles,
adds the hints, and looks at the repository itself:

- C-O1: compiled or temporary files tracked by git (`.o`, `vgcore.*`,
  `*~`…). **Epitech: Untrack Compiled and Temporary Files** removes them
  from git and adds them to `.gitignore`.
- C-O2: C sources with another extension.
- C-O4: file and folder names that aren't snake_case.

The sidebar groups everything by rule; click an entry to open it.
